# ENDO_AI

Endogenous growth models for simulating AI scenarios.

Each model version has its own folder. Every version folder contains `src/` (code), `doc/` (detailed documentation with equations) and `output/` (all model results).

| Version | Description |
|---|---|
| [v1.0](v1.0/) | Task-based semi-endogenous growth model with automated research, recursive AI-software progress, and compute/power constraints. Rule-based closure; three scenarios plus a 6,000-draw Monte Carlo. |
| [v2.0](v2.0/) | Perfect-foresight general equilibrium: Ramsey households, no-arbitrage investment in compute (with expected chip-price declines), and AI labs that choose R&D to maximise the present value of profits. Three scenarios, comparison with v1.0, and a 100-draw Monte Carlo. |
